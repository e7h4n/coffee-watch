# Brewer icon assets

V60 and AeroPress are SVG reconstructions of the visual references supplied during product design. They are not byte-for-byte copies of a verified upstream source file. Before public redistribution, verify the original artwork's provenance/license or replace with independently cleared assets. No blanket repository license is asserted over supplied reference artwork.

Switch and Hoop were drawn for this prototype using official product structures as visual references:

- https://www.hario.cc/Items/coffee/SSD-INT-200-B.html
- https://www.ceado.com/en/products/pour-over-coffee-brewer/

V60 is handle-free. Switch has a small detached inclined rounded-rectangle lever and no bottom protruding dot. Their viewBoxes center the main brewer body rather than the lever/handle bounds. The prototype embeds these shapes inline.
